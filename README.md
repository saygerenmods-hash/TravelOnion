# 🌍 TravelOnion — Туры и путешествия

TravelOnion — учебное веб-приложение для просмотра и управления туристическими путешествиями.

Проект реализован с использованием **ASP.NET Core Web API, Angular и SQLite**. Пользователи могут просматривать туры, искать путешествия по заданным параметрам, регистрироваться, авторизоваться и управлять собственными турами.

## Технологии

**Backend:**
- C# / ASP.NET Core (.NET 10)
- Minimal API
- Entity Framework Core
- SQLite
- FluentValidation
- JWT Authentication
- Swagger / OpenAPI

**Frontend:**
- Angular 22
- TypeScript
- HTML / CSS
- Angular Signals
- HttpClient и httpResource
- Angular Router

**Дополнительно:**
- Git / GitHub
- Visual Studio Code

## Основные возможности

- Просмотр списка туристических путешествий
- Просмотр подробной информации о туре
- Фильтрация по стране, максимальной цене и текущему месяцу
- Сортировка по цене и дате
- Постраничная навигация
- Регистрация и вход в аккаунт
- JWT-авторизация
- Создание новых туров
- Редактирование и удаление собственных туров
- Загрузка фотографий туров (JPG, PNG, WebP, до 5 МБ)
- Проверка корректности данных
- Разграничение прав доступа

## Архитектура проекта

Проект разделён на две основные части:

```text
TravelOnion/
├── client/                  # Angular
│   └── src/app/
│       ├── components/      # Переиспользуемые компоненты
│       ├── models/          # TypeScript-интерфейсы
│       ├── pages/           # Страницы приложения
│       └── services/        # API, авторизация и защита маршрутов
├── server/
│   └── TravelApi/
│       ├── Data/            # Контекст базы данных
│       ├── DTOs/            # Объекты передачи данных
│       ├── Models/          # Сущности
│       ├── Validators/      # Валидация
│       ├── Services/        # API endpoints и JWT
│       └── Migrations/      # Миграции EF Core
└── README.md
```

Backend предоставляет REST API, а Angular взаимодействует с ним через HTTP.

База SQLite хранит информацию о странах, турах и пользователях.

## Запуск проекта

### Требования

Перед запуском необходимо установить:

- .NET SDK 10
- Node.js и npm
- Git

### 1. Клонирование репозитория

```bash
git clone https://github.com/saygerenmods-hash/TravelOnion.git
cd TravelOnion
```

### 2. Настройка Backend

Перейдите в папку сервера:

```bash
cd server/TravelApi
```

Настройте JWT-ключ через .NET User Secrets:

```bash
dotnet user-secrets init
dotnet user-secrets set "Jwt:Key" "REPLACE_WITH_A_LONG_RANDOM_SECRET_KEY_AT_LEAST_32_CHARACTERS"
```

Значение JWT-ключа необходимо заменить собственным случайным секретом.

Восстановите зависимости:

```bash
dotnet restore
```

Примените миграции базы данных:

```bash
dotnet ef database update
```

Если команда `dotnet ef` недоступна, установите инструмент:

```bash
dotnet tool install --global dotnet-ef
```

Запустите API:

```bash
dotnet run
```

Адрес API:

http://localhost:5277

Swagger:

http://localhost:5277/swagger/index.html

### 3. Запуск Frontend

Откройте второй терминал:

```bash
cd client
npm install
npm start
```

На Windows PowerShell при блокировке npm-скриптов используйте `npm.cmd install` и `npm.cmd start`.

Откройте:

http://localhost:4200

**Важно:** Angular и ASP.NET Core должны работать одновременно.

## REST API

| Метод | Маршрут | Описание | Доступ |
|---|---|---|---|
| GET | `/api/tours` | Список туров | Публичный |
| GET | `/api/tours/{id}` | Подробности тура | Публичный |
| POST | `/api/tours` | Создание тура | Авторизованный |
| PUT | `/api/tours/{id}` | Редактирование | Автор тура |
| DELETE | `/api/tours/{id}` | Удаление | Автор тура |
| POST | `/api/tours/{id}/image` | Загрузка фотографии | Автор тура |
| POST | `/api/auth/register` | Регистрация | Публичный |
| POST | `/api/auth/login` | Авторизация | Публичный |

### Фильтрация и пагинация

Пример:

```http
GET /api/tours?countryId=1&maxPrice=1500&page=1&pageSize=5&sortBy=price
```

Поддерживаемые параметры:

- `countryId` — страна
- `maxPrice` — максимальная стоимость
- `currentMonth` — туры текущего месяца
- `sortBy` — сортировка по цене или дате
- `page` — номер страницы
- `pageSize` — количество туров на странице

## База данных

Используется SQLite и Entity Framework Core.

Основные сущности:

**Country** — страна путешествия.

**Tour** — туристическое предложение с названием, датами, ценой, количеством мест, страной, фотографией и автором.

**User** — пользователь приложения.

Связи:

- Одна страна может иметь несколько туров.
- Один пользователь может создать несколько туров.
- Каждый тур принадлежит одному автору.

Начальные данные включают пять стран и пять туристических предложений.

## Безопасность

- Пароли хранятся в виде защищённых хешей.
- Для авторизации используются JWT-токены.
- Создание туров требует авторизации.
- Редактирование, удаление и загрузка фотографий доступны только автору тура.
- JWT-ключ хранится вне репозитория через User Secrets.
- Данные запросов проверяются FluentValidation.
- Для фотографий предусмотрены ограничения формата и размера.

## Тестирование

API можно проверить через Swagger и файл `TravelApi.http`.

Основные проверяемые HTTP-статусы:

- `200 OK` — успешное получение или обновление данных
- `201 Created` — создание ресурса
- `204 No Content` — успешное удаление
- `400 Bad Request` — некорректные данные
- `401 Unauthorized` — пользователь не авторизован
- `403 Forbidden` — недостаточно прав
- `404 Not Found` — ресурс не найден
